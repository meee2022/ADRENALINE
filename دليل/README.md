# دليل أدرينالين

أوراق مرجعية للطاقم — **قواعد التشغيل**، لا توثيق كود.

كل ورقة صفحة HTML واحدة تُفتح بالضغط عليها مباشرةً (بلا خادم ولا إنترنت)، وتُطبع
من المتصفح كما هي.

## الأوراق

|---|---|---|

## متى تُضاف ورقة هنا

كل قاعدة تشغيلية **يُشرح لبسها بالكلام أكثر من مرة** تستحق ورقة. المعيار: لو
احتاج أحدهم شرحاً شفهياً مرتين، فالورقة أوفر من الشرح الثالث.

ليس هنا: توثيق الكود (مكانه `CLAUDE.md` والتعليقات)، ولا القرارات المؤقتة.

## عند التعديل

الورقة مكتوبة بالعربية RTL وتعمل في الوضع الفاتح والداكن. الألوان من متغيّرات
CSS في أعلى الملف — عدّلها هناك لا في العناصر.

⚠️ **الأرقام في الأوراق أمثلة من بيانات حقيقية وقت الكتابة.** لو تغيّرت القاعدة
نفسها (أيام العمل، دورة الإكسل) فحدّث الورقة — فالطاقم يعتمد عليها.
