## ٢ — ما تحتاج تثبيته على الجهاز

**Android Studio وحده** — من `developer.android.com/studio`، وعند أول تشغيل
اقبل تنزيل *Android SDK* و*Build-Tools*.

> **جافا:** Capacitor 8 يترجم بـJava 21، وجافا النظام هنا 17. لا تحتاج تثبيت
> جافا أخرى — `script/android-gradle.ts` يجد الجافا التي بداخل Android Studio
> ويستعملها تلقائياً. ولو ثبّتّ JDK في مكانٍ آخر، اضبط
> `CAPACITOR_ANDROID_JAVA_HOME` عليه.

**متحقَّق منه:** بُني `app-debug.apk` بنجاح على هذا الجهاز بهذه الطريقة.

## ٣ — مفتاح التوقيع (مرّة واحدة في عمر التطبيق)

⚠️ **لو ضاع هذا الملف أو كلمة سرّه، لن تستطيع رفع أي تحديث للتطبيق أبداً.**
احفظ نسخةً منه خارج الجهاز (مثلاً في OneDrive في مجلد مقفول).

```bash
keytool -genkeypair -v -keystore android/adrenaline-release.jks -keyalg RSA -keysize 2048 -validity 10000 -alias adrenaline
```

ثم انسخ `config/keystore.properties.example` إلى `android/keystore.properties`
واملأ كلمتَي السرّ فيه. الملفان الاثنان مستثنيان من Git.

## ٤ — ضبط قاعدة البيانات للإصدار

انسخ `config/android.env.example` إلى **`client/.env.android.local`**، وضع فيه
رابط Convex **الإنتاج**، ثم اجعل `ANDROID_RELEASE_CONFIRMED=true`.

## ٥ — البناء

```bash
npm run android:bundle
```

الناتج: `android/app/build/outputs/bundle/release/app-release.aab` — وهذا ما
يُرفع إلى Play (المتجر لا يقبل APK للتطبيقات الجديدة).

للتجربة على جوّالك قبل الرفع:

```bash
npm run android:apk
```

الناتج `android/app/build/outputs/apk/debug/app-debug.apk` — انقله للجوّال
وثبّته. أو افتح المشروع في Android Studio بـ`npm run android:open` وشغّله
على جهازٍ موصول.

> ⚠️ **حجم التطبيق ≈ ٩٥ ميجا**، لأن كل صور المشروع تُحزَم داخله:
> `pos-meals` ٢٢م · `profile` ١٦م · وصور دعائية عدّة كلٌّ منها ٢م.
> يشتغل، لكنه كبير على تطبيق مطعم. **تصغيره قبل الرفع للمتجر يستحقّ جلسة
> مستقلّة** — أغلب هذه الصور لا يحتاجها تطبيق الجوّال أصلاً.

3. ارفع `adrenaline-v1.0.aab` ← Release name: `1.0` ← **Save** ← **Review release** ← **Start rollout**
