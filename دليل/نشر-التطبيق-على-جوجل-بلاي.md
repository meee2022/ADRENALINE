# نشر تطبيق أدرينالين على Google Play

> المشروع مُهيَّأ بالكامل لأندرويد. هذا الملف يشرح ما تبقّى — وهو ما لا أستطيع
> عمله بدلاً عنك: تثبيت أدوات أندرويد، وإنشاء مفتاح التوقيع، وحساب Play.

## ٢ — ما تحتاج تثبيته على الجهاز

1. **JDK 21** — الموجود حالياً ١٧، وCapacitor 8 يطلب ٢١.
   نزّل *Microsoft Build of OpenJDK 21* واضبط `JAVA_HOME` عليه.
2. **Android Studio** — من `developer.android.com/studio`.
   عند أول تشغيل اقبل تنزيل *Android SDK Platform 36* و*Build-Tools*.

بعدها تأكّد أن `android/local.properties` فيه مسار الـSDK (يكتبه Studio تلقائياً).

## ٣ — مفتاح التوقيع (مرّة واحدة في عمر التطبيق)

⚠️ **لو ضاع هذا الملف أو كلمة سرّه، لن تستطيع رفع أي تحديث للتطبيق أبداً.**
احفظ نسخةً منه خارج الجهاز (مثلاً في OneDrive في مجلد مقفول).

```bash
keytool -genkeypair -v -keystore android/adrenaline-release.jks -keyalg RSA -keysize 2048 -validity 10000 -alias adrenaline
```

ثم انسخ `config/keystore.properties.example` إلى `android/keystore.properties`
واملأ كلمتَي السرّ فيه. الملفان الاثنان مستثنيان من Git.

## ٤ — ضبط قاعدة البيانات للإصدار

انسخ `config/android.env.example` إلى **`client/.env.android.local`**، وضع فيه
رابط Convex **الإنتاج**، ثم اجعل `ANDROID_RELEASE_CONFIRMED=true`.

## ٥ — البناء

```bash
npm run android:bundle
```

الناتج: `android/app/build/outputs/bundle/release/app-release.aab` — وهذا ما
يُرفع إلى Play (المتجر لا يقبل APK للتطبيقات الجديدة).

للتجربة على جوّالك قبل الرفع:

```bash
npm run build:android:dev
npm run android:open
```

ثم شغّله من Android Studio على جهاز موصول.

## ٦ — Play Console

1. حساب مطوّر: **٢٥ دولاراً مرّة واحدة**.
2. أنشئ تطبيقاً جديداً، وارفع الـ`.aab` في مسار **Internal testing** أولاً.
3. المطلوب في صفحة المتجر:
   - أيقونة ٥١٢×٥١٢ → `android/play-store-icon-512.png`
   - صورة غلاف **١٠٢٤×٥٠٠**
   - **٢ لقطات شاشة على الأقل** للهاتف
   - وصف قصير (٨٠ حرفاً) ووصف كامل
4. **سياسة الخصوصية** — رابط عام إلزامي.
5. استمارة **Data safety**: التطبيق يجمع الاسم والهاتف والبريد وبيانات صحية
   (أهداف التغذية والحساسية) — يجب الإفصاح عنها، وإلا رُفض.
6. التطبيق يقبل مدفوعات لخدمة تُسلَّم خارج التطبيق (وجبات فعلية)، فيُسمح
   بالدفع عبر PayLater ولا يُلزَم بفوترة Google. اذكر ذلك إن سُئلت.

## ٧ — التحديثات لاحقاً

قبل كل رفعة، ارفع الرقمين في `android/app/build.gradle`:

```
versionCode 2        // رقم صحيح يزيد في كل رفعة — Play يرفض التكرار
versionName "1.1"    // ما يراه المستخدم
```
