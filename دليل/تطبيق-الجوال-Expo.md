# تطبيق الجوال (Expo) — `apps/mobile`

تطبيق العميل بواجهات أصلية (React Native) على **نفس قاعدة Convex ونفس القواعد المشتركة**
(`shared/rules`). لوحة التحكم وصفحات الطاقم تبقى ويب وتُفتح داخل التطبيق كما هي.

## التشغيل على جوالك (بلا بناء)
1. ثبّت **Expo Go** من App Store / Play.
2. من جذر المشروع:
   ```bash
   npm --prefix apps/mobile start
   ```
   (أول مرة: `npm --prefix apps/mobile install`). لو الجوال على شبكة مختلفة أضف `-- --tunnel`.
3. امسح QR من الطرفية بكاميرا الآيفون أو من تطبيق Expo Go على أندرويد.
4. أول تشغيل: التطبيق يفرض العربية RTL ويُعيد التحميل مرة واحدة — طبيعي.

معاينة على المتصفح (للتطوير فقط): `npm --prefix apps/mobile run web -- --port 8090`.
⚠️ لوحة التحكم لا تظهر داخل معاينة الويب (الموقع يمنع تضمينه في iframe)، لكنها تعمل على
الجهاز الحقيقي عبر WebView.

## البنية
| المسار | ماذا فيه |
|---|---|
| `app/_layout.tsx` | خطوط Cairo، Convex، السبلاش المتحرّك، RTL |
| `app/(tabs)/index.tsx` | الرئيسية: هيرو، صف ثقة، الخطط، الأكثر طلباً، آراء، أسئلة، ختام |
| `app/(tabs)/menu.tsx` | القائمة: بحث + كبسولات + شبكة بطاقات (تصفّح فقط حالياً) |
| `app/meal/[id].tsx` | تفاصيل الطبق (نافذة من الأسفل) |
| `app/(tabs)/plans.tsx` | الباقات بمددها الثلاث — الاشتراك عبر واتساب |
| `app/(tabs)/account.tsx` | حسابي (الدخول برقم الهاتف لاحقاً) + زر لوحة التحكم |
| `app/admin.tsx` / `admin.web.tsx` | لوحة التحكم: WebView على الجهاز، iframe على الويب |
| `src/api.ts` | عنوان Convex والموقع من `app.json → extra`؛ نفس أسماء الاستعلامات |
| `src/rules.ts` | إعادة تصدير `shared/rules` — لا قاعدة تُكتب هنا |
| `src/theme.ts` / `src/components` | الهوية (كحلي `#0B2138`، سماوي `#3CC4F0`)، بطاقة الطبق، الأزرار |
| `assets/` | أيقونة، طبقة تكيّفية، سبلاش، شعار الكلمة — تُولَّد بـ `npx tsx script/make-mobile-assets.ts` |

## ما لم يُبنَ بعد (بالترتيب)
1. دخول المشترك برقم الهاتف واختيار وجبات أيامه (بنفس قواعد `shared/rules` وتحقّق الخادم).
2. مراجعة الطلب وإرساله (نفس `customerOrders.create`) ثم التتبّع.
3. الإشعارات، ثم البناء عبر EAS Build ورفع المتاجر بدل تطبيق Capacitor.
