# Adrenaline Orders Alert — إضافة تنبيه الطلبات

إضافة متصفح صغيرة تراقب لوحات **طلبات / سنونو / رفيق** المفتوحة عندك، وأول ما يجيلك **طلب جديد** من أي منصّة، تطلق **إشعار موحّد + صوت** — فماتحتاجش تبصّ على الشاشات طول الوقت.

- ✅ **بدون كلمات مرور** — بتشتغل داخل جلستك المفتوحة أصلاً.
- ✅ **بدون إرسال بيانات** — كل حاجة محلية على جهازك، مفيش أي طلب بيتبعت لأي سيرفر.
- ✅ صوت + إشعار نظام + وميض في عنوان التبويب.

## التركيب (مرة واحدة)

1. افتح Chrome → اكتب في العنوان: `chrome://extensions`
2. فعّل **Developer mode** (أعلى اليمين).
3. اضغط **Load unpacked** → اختر مجلّد `orders-bridge-extension`.
4. أول مرة، اسمح للإشعارات لو طلب.

## الاستخدام

- افتح شاشات المنصّات (زر **شاشة المتابعة** جوّه التطبيق، أو اختصار "Online Orders").
- سيبها مفتوحة (حتى لو مصغّرة) — أول ما يجيلك طلب، هيجيلك **إشعار + صوت** بالمنصّة.

## لو منصّة توقّف كشفها

عدّادات المنصّات ممكن تتغيّر شكلها. لو منصّة بطّلت تنبّه:
- افتح لوحتها، افتح Console (F12)، شوف الرقم اللي المفروض يتقرأ (عدد الطلبات النشطة).
- عدّل دالة `getCount` في `content.js` للمنصّة دي.
- أو ابعتلي شكل صفحة الطلبات وأظبطها.

> ملاحظة: دي حل مؤقت عملي لحد ما أي منصّة توفّر **API رسمي** — ساعتها الطلبات هتنزل جوّه تطبيق أدرينالين مباشرة (المستقبِل جاهز).
