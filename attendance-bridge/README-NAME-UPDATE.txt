ADRENALINE HIKVISION NAME UPDATE

1. Extract this ZIP completely into a new folder on the restaurant PC.
2. Right-click UPDATE-PERSON-NAMES.bat and choose Run as administrator.
3. Review the preview list.
4. Type UPDATE only when the displayed Person IDs and names are correct.
5. Wait for SUCCESS. Do not close the window while it is applying changes.

Safety:
- Only employeeNo (Person ID) and name are sent to Hikvision.
- Fingerprints, cards, validity and attendance events are not deleted.
- A local person-names-backup-*.json file is created before applying.
- The attendance bridge is stopped briefly and restarted automatically.
